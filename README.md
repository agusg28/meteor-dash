METEOR DASH is a tiny neon arcade browser game — pilot a little ship, dodge falling meteors, collect stars — built by an AI agent from a single prompt, and entered on make.fun with its X video post.

Open `game/index.html` in a browser to play it — arrows/WASD or touch drag to fly.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
